# Loot Drop vertical slice (archived)

Phaser 3 + React shell vertical slice that lived on `main` before the arcade
multiplayer prototype was merged. Preserved here so art, systems, and docs stay
in the repo.

The runnable product is the arcade React + Socket.IO game at the monorepo root
(`pnpm dev`). This folder is reference material / future Phaser integration —
it is not wired into the default app entry, and is excluded from typecheck/lint.
