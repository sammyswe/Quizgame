# Inbox

Drop raw meeting notes and half-formed ideas here.

## Workflow

1. Create a new note in this folder after a design chat
2. Use [[Idea Intake Template]]
3. Split into atomic notes under the right area folder
4. Link from the area MOC
5. Delete or archive the inbox stub once filed

## Starter prompts for meetings

- What part of the game are we talking about? (link the MOC)
- Is this LOCKED / PILOT / IDEA / REJECTED?
- What would make us reject it?
- What animation communicates the rule?
