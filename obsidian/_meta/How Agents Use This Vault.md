# How Agents Use This Vault

1. Start at [[Home]] and the relevant area MOC.
2. Also load `docs/context/INDEX.md` for the compact task router.
3. Prefer LOCKED notes for direction; treat IDEA notes as brainstorms.
4. Verify implementation claims in code (`shared/`, `server/`, `client/`).
5. After a product decision from a meeting: capture in `00-Inbox/`, then promote into an atomic note and update status.
6. Do not silently ship IDEA content. Do not erase REJECTED history.
