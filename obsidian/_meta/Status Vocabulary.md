# Status Vocabulary

Canonical decision language shared with `docs/context/STATUS.md`.

| Status | Meaning | Agent behaviour |
| --- | --- | --- |
| **LOCKED** | Owner confirmed | Preserve; gaps are TODOs |
| **PILOT** | Active playtest | Keep playable; change only for the named test |
| **IDEA** | Worth retaining | Discuss; never present as decided |
| **REJECTED** | Declined or superseded | Do not revive without new evidence |

Also see [[Conventions]] and [[How Agents Use This Vault]].
