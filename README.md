# IQ Party — Design Bank

Canonical **product & visual decision bank** for IQ Party (Treasure Trap fantasy).

This repository contains **docs, Obsidian notes, and Cursor agent skills/rules** — not a game runtime.

Engineering rebuilds happen in a separate code repo, against the LOCKED decisions here.

## Start here

| Audience | Open first |
| --- | --- |
| Humans | [`RESTART.md`](RESTART.md) → [`AGENT_LOOP_ROADMAP.md`](AGENT_LOOP_ROADMAP.md) → Obsidian `_MOCs/Home.md` |
| Agents | [`AGENTS.md`](AGENTS.md) → `docs/context/INDEX.md` → `docs/context/HANDOFF.md` |
